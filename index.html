About Me

Welcome to my CS-499 Computer Science Capstone ePortfolio. This website showcases my work, technical skills, and improvements to projects completed during my degree.

My main artifact is Travlr Getaways, a full-stack application originally developed in CS-465. I am enhancing this project in three areas: software engineering, algorithms and data structures, and databases.

Software Design and Engineering

My first enhancement focuses on improving the security of Travlr Getaways. I added JWT authentication, created an Angular login page, and protected administrative routes so users must be authenticated before accessing certain features. I also updated the back end to require authentication when adding, editing, or deleting trips.

This enhancement helped me better understand how front-end and back-end security work together. I also gained experience troubleshooting an existing application and using GitHub to manage my changes. The administrator login has been tested successfully, and I plan to make any additional improvements based on my instructor's feedback.
